# PdfTabs

A Flutter PDF reader app. Pick a PDF file and read it with in-app text search.

## Features

- Open PDF files from the device via the system file picker
- Read documents with text selection enabled
- Search within a PDF with match highlighting and next/previous navigation
- Light, dark, and system theme modes

## Getting Started

This project is built with Flutter. Run it with:

```sh
flutter pub get
flutter run
```

For help getting started with Flutter development, view the
[online documentation](https://docs.flutter.dev/).
